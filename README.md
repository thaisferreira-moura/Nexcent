## 📄 Descrição do entregável

* **index.html** — Arquivo principal do projeto, responsável pela estrutura da página.

* **style.css** — Arquivo responsável pela estilização, layout, cores, espaçamentos e responsividade da aplicação.

* **img** — Pasta contendo as imagens e elementos visuais utilizados no projeto.

---

<!-- ---------------------------------------------------------------------- -->

## 💻 Sobre o projeto

NextCent é um projeto desenvolvido durante meus estudos em **Desenvolvimento Front-End**, utilizando **HTML5 e CSS3**.

O objetivo foi desenvolver uma página web moderna e responsiva para uma plataforma de serviços, aplicando conceitos de **HTML semântico, estruturação de conteúdo, estilização com CSS, organização do código e criação de interfaces responsivas**.

O projeto foi desenvolvido com foco na prática dos fundamentos de Front-End e na construção de uma interface visualmente organizada e agradável para o usuário.

## 🚀 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo **index.html** no navegador.

### Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina:

* Um navegador como **Google Chrome**, Microsoft Edge ou Firefox.
* Um editor de código como [VSCode](https://code.visualstudio.com/).
